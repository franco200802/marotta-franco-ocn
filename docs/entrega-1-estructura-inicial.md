# Estructura inicial del proyecto

Este repositorio contiene la estructura base solicitada para comenzar el desarrollo.

## Formato de repositorio en GitHub

Nombre sugerido: `apellido-nombre-negocio`

Ejemplo: `marotta-franco-veterinaria`

## Estructura creada

```text
Proyecto/
  Frontend/
  Backend/
    src/
      models/
```

## Modelo de dominio

Se documentó el modelo de dominio en `Backend/DIAGRAMA_CLASES.md`, basado en el análisis de requerimientos de `Proyecto de Desarrollo de Sistema.docx` (Sistema de Gestión de Ventas para OCN Villa Urquiza).

### Entidades incluidas

- Cliente
- Administrador
- Producto
- Pedido
- DetallePedido
- Envio

### Alcance de esta entrega

- Solo clases con atributos
- Sin lógica de negocio
- Sin base de datos
- Sin Express
